# 🍽️ Grand Bistro - Restaurant Management System

A premium, full-stack restaurant management application built with **Flask** and **SQLAlchemy**. This system features a luxury-themed customer interface and a comprehensive administrative dashboard.

## ✨ Key Features

* **🛒 Digital Menu & Cart:** A fully responsive menu with category filtering and an interactive shopping cart.
* **📅 Table Reservations:** Online booking system for customers to reserve tables in advance.
* **🤖 AI Concierge:** Integrated chatbot that captures customer inquiries and stores them for admin review.
* **🔐 Admin Dashboard:** * **Order Management:** Track and complete customer orders in real-time.
    * **Reservation Tracking:** View and manage guest seating schedules.
    * **Menu Editor:** Add, update, or remove dishes directly from the UI.
    * **Inquiry Portal:** Read messages sent via the chatbot.
    * **Security Settings:** Update administrative login credentials.

## 🛠️ Tech Stack

* **Backend:** Python (Flask)
* **Database:** SQLite (SQLAlchemy ORM)
* **Frontend:** HTML5, CSS3 (Bootstrap 5, Google Fonts)
* **Mailing:** Flask-Mail (SMTP Integration)
